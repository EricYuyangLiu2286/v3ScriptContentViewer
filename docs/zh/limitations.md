# 限制

- **只做静态读取。** v3tree 不运行游戏，判断不了日志的 `possible` 何时被检查、某个 on_action 是否由引擎触发、scope 在运行时指向谁。
- **不计算条件。** `NOT = { has_variable = x }` 与 `has_variable = x` 一样记为读取 `x`；不区分与、或、否。
- **覆盖规则未经实证。** 启动器的加载顺序、`REPLACE:`/`INJECT:` 的语义、无前缀同名定义“先读到的为准”，依据的是惯例和外部说明，不是游戏目录里的文件。旁证见 `how-it-works.md`。
- **不建索引的内容：** 国家定义的字段、GUI 文件、地图、州与人口历史、建筑与生产方式。反向检查会把 GUI 文件中的出现列为未解释。
- **文件夹清单。** 建索引的文件夹按 1.15 版定；新版本新增的文件夹，用配置里的 `extra_folders` 补上。
- **步数搜索的边界较粗。** 停止规则只是阈值；和其他系统纠缠深的系统，每一轮都需要手动剪枝。
- **上下文标签只有一种语言。** 索引里的标签用建索引时的界面语言；切换语言后请重建索引。
- **步数搜索不判软边。** 软边只在判定文件里判定（AI 或手工）。
- **大图。** 超过约 1000 个节点时布局变慢；可以折叠层级、按类型筛选，或收窄主题。
- **不附带接口清单。** 它属于游戏数据；没有时只跳过“未识别键”这一项诊断。
